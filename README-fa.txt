انبار من - نسخه دوم حسابداری برای آیفون

نصب روی GitHub Pages:
1) از مخزن GitHub خود یک نسخه پشتیبان بگیر یا از آن یک مخزن جدید بساز.
2) این نسخه را فقط پس از نگه‌داشتن فایل‌های نسخه قبلی منتشر کن.
3) فایل‌های داخل پوشه anbar_man_v2 را در ریشه مخزن (همان جایی که index.html دیده می‌شود) بارگذاری و Commit کن.
4) در Settings > Pages مطمئن شو Branch=main و Folder=/(root) است.
5) پس از انتشار، Safari را باز کن و سایت را دوباره بارگذاری کن. اگر نسخه قدیمی از حافظه نمایش داده شد، Service Worker سایت را از نو بارگذاری کن یا چند لحظه صبر کن.

ذخیره‌سازی:
- داده‌های این نسخه در localStorage با کلید anbar-man-accounting-v2 ذخیره می‌شود.
- پایگاه داده IndexedDB نسخه قبلی با نام anbar-man-db خودکار پاک نمی‌شود، اما نسخه دوم مستقیماً آن را نمی‌خواند.
- برای انتقال کالاها از نسخه قبلی، در نسخه قبلی از قسمت پشتیبان یک فایل JSON بگیر و در نسخه جدید بخش پشتیبان > واردکردن پشتیبان نسخه قبلی را انتخاب کن. این واردسازی کالاها و موجودی فعلی را منتقل می‌کند؛ سوابق گردش قبلی به فاکتورهای مالی تبدیل نمی‌شوند.
- برای بازگرداندن پشتیبان کامل نسخه دوم از بخش پشتیبان استفاده کن.

محدودیت‌ها:
این یک نسخه اولیه و محلی برای کسب‌وکار کوچک است؛ هنوز دفترکل دوبل، بستن دوره، فاکتور چندردیفه، مالیات، چک‌های سررسیددار، ویرایش/ابطال اسناد، چاپ رسمی فاکتور یا همگام‌سازی بین دستگاه‌ها ندارد. قبل از اتکا برای حسابداری رسمی، آن را با داده آزمایشی بررسی کن و از اطلاعات پشتیبان بگیر.
